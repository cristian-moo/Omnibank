Tarea 1: Requerimientos No Funcionales de OmniBank

¿Que regla sobre el saldo (balance) solicita el Cto para proteger las cuentas?
R = La base de datos debe impedir que una cuenta tenga un saldo negativo, evitando errores del sistema que puedan dejar las cuentas en numeros menores a cero.

¿Como debe la Base de Datos manejar la eliminacion de cliente?
R = La base de datos debe impedir que un cliente sea eliminado despues de haber sido registrado. Si un cliente cierra su cuenta, su informacion debe conservarse y unicamente debe cambiar su estado a inactivo.

¿Que informacion temporal es obligatoria en las cuentas cada vez que sufren un cambio?
R = La fecha y hora debe ser registrada en la base de datos.

NFR1: La base de datos debe impedir que una cuenta tenga un saldo menor a 0.
NFR2: La base de datos debe impedir que un cliente sea eliminado, en su lugar, debe marcarse como inactivo.
NFR3: La base de datos debe guardar la fecha y hora de la actualizacion de una cuenta cada vez que sea modificada.

## Expected Result
El estudiante debe haber identificado las tres reglas de consistencia mencionadas en la actividad y el slack del CTO.

## Reference Solution
1. **NFR1 (Consistencia Matemática):** La base de datos debe impedir que las cuentas queden con saldos en números negativos.
2. **NFR2 (Auditoría / Soft Delete):** La base de datos debe impedir la eliminación física de un registro de cliente, y en su lugar debe poder marcarse como inactivo.
3. **NFR3 (Timestamps):** La base de datos debe registrar y actualizar automáticamente la fecha y hora exacta (`updated_at`) cada vez que el registro de una cuenta es modificado.

## Common Valid Variations
* "La tabla de clientes debe tener un campo booleano `is_active`." *(Esto ya es pensar en SQL, lo cual es muy bueno, aunque el requerimiento en lenguaje natural es suficiente).*

## Common Mistakes
* Confundir requerimientos funcionales con no funcionales. Por ejemplo, decir que "Un requerimiento es guardar el nombre del cliente", lo cual es Funcional (RF), no un Requerimiento No Funcional (NFR).
