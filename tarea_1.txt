Tarea 1: Requerimientos No Funcionales de OmniBank

¿Que regla sobre el saldo (balance) solicita el Cto para proteger las cuentas?
R = La base de datos debe impedir que una cuenta tenga un saldo negativo, evitando errores del sistema que puedan dejar las cuentas en numeros menores a cero.

¿Como debe la Base de Datos manejar la eliminacion de cliente?
R = La base de datos debe impedir que un cliente sea eliminado despues de haber sido registrado. Si un cliente cierra su cuenta, su informacion debe conservarse y unicamente debe cambiar su estado a inactivo.

¿Que informacion temporal es obligatoria en las cuentas cada vez que sufren un cambio?
R = La fecha y hora debe ser registrada en la base de datos.

NFR1: La base de datos debe impedir que una cuenta tenga un saldo menor a 0.
NFR2: La base de datos debe impedir que un cliente sea eliminado, en su lugar, debe marcarse como inactivo.
NFR3: La base de datos debe guardar la fecha y hora de la actualizacion de una cuenta cada vez que sea modificada.
